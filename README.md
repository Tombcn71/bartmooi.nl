# bartmooi.nl

Eén repository, drie onderdelen. Elk onderdeel is een eigen Vercel-project (Root Directory = de map) en heeft een eigen adres.

| Map | Wat | Adres |
|---|---|---|
| `website/` | bartmooi.nl in nl, en, de, pl (Next.js, snel en AI-vriendelijk) | bartmooi.nl |
| `offerte/` | offerte-app: calculator, AI-assistent Roos, offertes | offerte.bartmooi.nl |
| `kantoor/` | administratie: werkbonnen en uren, projecten, facturen | kantoor.bartmooi.nl |

Geheime sleutels staan niet in de repo (`.env*` wordt genegeerd); ze staan in Vercel per project.
